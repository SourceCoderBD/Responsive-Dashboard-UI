📊 Responsive Dashboard UI

A modern and responsive dashboard interface built with HTML, CSS, and JavaScript.

This project was created as a Front-End Development practice project to improve my skills in responsive layouts, CSS styling, and basic JavaScript interactions.

---

✨ Features

- 📱 Fully responsive layout
- 🖥️ Mobile, Tablet & Desktop support
- 📊 Dashboard statistics cards
- 📋 Recent Projects table
- 📈 Project progress bars
- 🏷️ Project status badges
- 🧭 Responsive sidebar navigation
- 🔔 Header notification section
- 👤 User profile section
- 🖼️ Annotation workspace preview
- ⚡ JavaScript menu interactions
- 🎨 Modern dark-themed UI

---

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
